# AeroLLM Lab 0.1.0

Version 0.1 demonstrates a reproducible NTSB-to-grounded-QA vertical slice: provenance-preserving ingestion and chunking, frozen event-family splits, measured retrieval/reranking baselines, and a base/prompted/RAG comparison using the pinned Ministral 3 3B Instruct checkpoint.

## Included outcomes

- Pilot corpus v1: 16 official-report documents, 2,017 pages, 6,897 chunks.
- Frozen test v1: 10 independently reviewed questions in held-out event family `DCA25MA108`; dataset SHA-256 `c095f7bd656f0dfebfdd7ea4cb221c7a11d76c7a6aef1df3ebd9cf952e044723`.
- Locked retrieval: BM25 Recall@10 0.500; hybrid Recall@10 0.700; hybrid plus reranker Recall@10 0.600, MRR@10 0.4833, nDCG@10 0.5131.
- Locked generation token F1: base 0.091, prompted 0.213, RAG 0.283. RAG gold evidence coverage was 0.600 and citation precision was 0.700.
- Corpus v2: NTSB provenance selection and event-family split frozen under version `ntsb-corpus-v2`. The generated 72-slot workbook has 27 development drafts awaiting review and 45 intentionally unauthored test slots.

The generation checkpoint is `mistralai/Ministral-3-3B-Instruct-2512`, revision `b35d4dfe56c142746f54dbd64f579faab2744308`. Development and all checked-in measurements used an RTX 4070 Laptop GPU with 8,188 MiB VRAM and a 45 W power limit.

## Known failure and limitations

The locked RAG run retrieved evidence from the wrong accident for a fatalities question and answered 15 rather than 67. This is a documented provenance failure, not a successful grounded answer. The small, answerable-only v1 test set cannot establish general reliability; token overlap misses semantic equivalence; citation format does not establish entailment; and latency figures are single-stream local measurements rather than serving benchmarks.

## Not included

QLoRA/SFT, SFT plus RAG, vLLM serving, tool calling, DPO, and the educational Transformer are not complete. Designs or configuration placeholders must not be read as delivered capabilities.
